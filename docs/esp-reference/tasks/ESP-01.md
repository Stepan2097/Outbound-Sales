## Опис і критерії
Джерело: артефакт «Чекліст ESP для cold email» v1 (09.10.2026), розділ «Підключення пошти», пункти P0. Стратегія й цифри: https://claude.ai/artifact/SCC2wo3cJ7aaPvjvAXSwRY. ESP — оркестратор поверх скриньок Google Workspace: вирішує, кому, з якої скриньки і коли надіслати; захист від помилок важливіший за функції.

Що зробити (P0, без цього перший холодний лист не відправляємо):
- Google OAuth без паролів: жодних паролів скриньок у базі чи таблицях; токени зашифровані, доступ до них лише сервісу відправки.
- Обрати модель доступу до скриньок у кількох Workspace ДО старту розробки: зовнішній OAuth-застосунок із Gmail-скоупами вимагає верифікації Google; простіше — service account з domain-wide delegation у кожному нашому Workspace або Internal-застосунок у кожному.
- Відправка через Gmail API: users.messages.send з threadId для фолоуапів (за даними Snov, через API відповідей удвічі більше, ніж через SMTP, кореляція).
- Відкликаний токен, помилка авторизації чи блок акаунта = пауза сендера й сповіщення людині; не повторювати спроби в циклі.
