## Опис і критерії
Джерело: «Чекліст ESP для cold email» v1, розділ «Лист і заголовки», пункти P0 (формат листа). Баг у новому коді (HTML замість тексту) спалить домени швидше, ніж погана база.

Що зробити:
- Лише text/plain: одна частина text/plain; charset=UTF-8, без text/html. Наш урок: текст із Google Docs тягнув форматування, і лист ставав HTML.
- Очищення шаблону при збереженні: знімати HTML-теги, стилі, нерозривні пробіли, невидимі символи; шаблон із тегами не зберігається.
- Ніякого трекінгу: без пікселя відкриттів, без переписування посилань, без трекінг-домену.
- Порожня змінна блокує лист: «Hi ,» не відправляється: або нейтральна заміна, або лід пропускається з причиною.
- Підпис лише текстом: ім'я, посада, ADvantage, сайт; для США ще поштова адреса юрособи. HTML-підпис із картинкою (як у старій таблиці) робить лист HTML.
